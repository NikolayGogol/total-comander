# Total Commander for macOS — Developer & Agent Documentation

> **AGENTS.md**: Цей файл містить повну архітектурну документацію, правила розробки, дизайн-систему, структуру модулів, гарячі клавіші та інструкції запуску проєкту.

## 1. Загальний огляд проєкту (Project Overview)

**Total Commander for macOS** — сучасний orthodox двопанельний файловий менеджер для macOS, розроблений на базі:

- **Node.js (Runtime)** + **Electron**: робота з файловою системою macOS POSIX (диски `/Volumes`, системні директорії, APFS), нативне переміщення у Смітник macOS (`shell.trashItem`) та безповоротне видалення (`fsPromises.rm`), виклик macOS QuickLook (`qlmanage -p`), показ об'єктів у нативному Finder (`shell.showItemInFolder`), відкриття системного macOS Terminal (`open -a Terminal`) у поточній папці та запуск файлів у нативних програмах за замовчуванням (як у Finder).
- **macOS Unlocker (Розблокування файлів та процесів)**: виявлення процесів, що утримують дескриптори відкритих файлів/папок (`/usr/sbin/lsof`), примусове завершення процесів (`kill -9`), скидання macOS immutable flags (`chflags -R nouchg,noschg`) та відновлення прав запису (`chmod -R u+w`) з можливістю автоматичного видалення, переміщення або копіювання після розблокування.
- **Нативні іконки файлів macOS**: пряме отримання системних іконок через `app.getFileIcon` з пакетним завантаженням та спільним кешем.
- **Вбудований повнофункціональний архіватор**: нативна підтримка створення та читання архівів через Apple `/usr/bin/ditto`, `/usr/bin/tar` та `/usr/bin/zip` безпосередньо через IPC-міст Electron. Підтримка захисту паролем (`zip -P`), вибору рівня компресії, віртуальної навігації за хлібними крихтами (breadcrumbs) та введення пароля для зашифрованих архівів.
- **Аналізатор диска та великих файлів (Disk Cleanup / Large Files Finder)**: сканер файлів гігантського розміру з пресетами (>10MB ... >2GB), швидким вибором дисків (Macintosh HD, Home ~, /Volumes), безпечним захистом критичних системних файлів та віртуальних дисків Docker від видалення.
- **Потоковий аналіз розміру папок (Real-time Folder Size)**: багатопотоковий розрахунок розміру підпапок з подіями у реальному часі (`onFolderSizeItem`, `onFolderSizeProgress`), візуальними шкалами часток та картками підсумків.
- **Зміна ширини колонок перетягуванням (Resizable Columns)**: інтерактивні розділювачі на межах колонок (`NAME`, `EXT`, `SIZE`, `MODIFIED`, `PERMS`) з плавним drag-and-drop, збереженням у `localStorage` та подвійним кліком для скидання ширини.
- **Vue 3 (Composition API)** + **TypeScript**: реактивний інтерфейс, двопанельна координація, підтримка вкладок у кожній панелі, фільтрація, гарячі клавіші.
- **SCSS Design System**: повністю модульна система стилів без інлайн-стилів із підтримкою темної та світлої тем, семантичних токенів кольорів і кастомних тонких скролбарів.
- **Day.js** (форматування дат) та **Numeral.js** (форматування розмірів файлів і чисел).
- **Lucide Icons**: семантичні системні іконки.

## 2. Суворі правила кодової бази (Mandatory Code Rules)

1. **Стилі виключно у SCSS файлах**:
   - Жодних блоків `<style>` у Vue-компонентах.
   - Усі стилі розташовані в `src/styles/` та імпортуються через `main.scss`.
2. **Кольори та розміри через змінні**:
   - Усі кольори визначені через SCSS змінні (`$color-bg-app`, `$color-accent-blue`, тощо).
   - Усі відступи (padding, margin), радіуси та розміри кнопок/панелей визначені через змінні (`$size-space-md`, `$radius-sm`, `$size-btn-icon`, тощо).
3. **Розміри шрифтів через змінні**:
   - Використовуються змінні: `$font-size-2xs`, `$font-size-xs`, `$font-size-sm`, `$font-size-base`, `$font-size-md`, `$font-size-lg`, `$font-size-xl`.
4. **Ніяких інлайн-стилів**:
   - Атрибут `style="..."` суворо заборонений у шаблонах `.vue`.
   - Замість цього використовуються семантичні класи або динамічні CSS Custom Properties, що встановлюються через DOM `element.style.setProperty()` в скриптах.
5. **Модульність та компонентний поділ**:
   - Кожен компонент має чітку відповідальність. Допоміжні компоненти < 150 рядків.
6. **Поведінка Finder на подвійний клік**:
   - Подвійний клік на файл викликає асоційовану програму macOS (`electronAPI.openPath`).
   - Подвійний клік на ярлик / псевдонім macOS Finder (`com.apple.alias-file` / `<LNK>`): миттєво запускає цільову програму чи відкриває цільовий файл, або переходить у цільову папку, показуючи фірмову нативну іконку цілі з бейджем `↗`.
   - Подвійний клік на архів (`.zip`, `.tar`, `.gz`, `.tgz`, `.bz2`, `.7z`, `.rar`) відкриває вбудований переглядач архівів `ArchiveViewModal`.
   - Подвійний клік на директорію переходить у неї.
   - Подвійний клік на `.app` запускає програму, а через контекстне меню доступна опція «Показати вміст пакета».
7. **Форматування**:
   - Форматування дат: **`dayjs`** (`formatDate`).
   - Форматування чисел та розмірів байтів: **`numeral`** (`formatBytes`, `formatNumber`).
8. **Безпечна IPC-серіалізація (Structured Clone Safety)**:
   - Об'єкти та масиви з реактивного стану Vue 3 (Reactive Proxy) перед відправкою через `window.electronAPI` проходять очищення (`toPlain()` / JSON-серіалізацію), що унеможливлює помилку `DOMException: An object could not be cloned` в Electron.
9. **Версіонування та автоматичний білд**:
   - Версія програми задається в `package.json`.
   - Скрипт `scripts/update-build-info.js` автоматично генерує `src/buildInfo.ts` з номером версії, номером збірки (`BUILD_NUMBER`) та точною датою збірки (`BUILD_DATE`).
10. **Імпорти виключно через аліас `@/`**:
    - Усі внутрішні імпорти компонентів, утиліт, сервісів та TypeScript-типів у папці `src/` суворо **мають використовувати аліас `@/`** замість відносних шляхів (`./`, `../`, `../../`).
    - Наприклад:
      - `import TitleBar from '@/components/TitleBar.vue'`
      - `import type { FileItem } from '@/types'`
      - `import { formatBytes } from '@/utils/formatters'`
      - `import FileTable from '@/components/pane/FileTable.vue'`
    - Використання відносних шляхів для внутрішніх модулів проєкту суворо заборонено.
11. **Модульність, ліміт розміру файлів та заборона дублювання (DRY & Single Responsibility)**:
    - Файли коду не повинні перетворюватися на моноліти (суворе обмеження: **до 700 рядків коду**). Файли розбиваються на логічні модулі, composables та дочірні компоненти:
      - Стан та бізнес-логіка Vue виносяться у composables в `src/composables/` (`usePanes`, `useShortcuts`, `useFileOperations`, `useModals`, `useDrives`, `useClipboard`, `useTableColumns`, `useToast`).
      - IPC-обробники Electron розділені за доменами у `electron/ipc/` (`fileSystem.ts`, `disk.ts`, `archive.ts`, `clipboard.ts`, `utils.ts`) та `electron/menu.ts`.
      - SCSS-стилі компонентів виносяться в окремі модульні файли у `src/styles/components/`.
    - Сувора заборона дублювання коду (DRY): спільна логіка виносяться утиліти чи міксини.
12. **Безпека системи та захист критичних файлів**:
    - Аналізатор великих файлів (`LargeFilesModal` / `analyzeDisk`) та операції видалення суворо захищають та автоматично виключають життєво важливі системні файли: віртуальні диски Docker (`Docker.raw`, `Docker.qcow2`), віртуальні машини (`/Containers/com.docker.docker/`), системний swap (`swapfile*`, `sleepimage`), ядро macOS та метадані APFS.
13. **Drag-and-Drop (DND)**:
    - Підтримка перетягування файлів між лівою та правою панелями, у підпапки та з зовнішнього Finder / Desktop macOS з коректним вилученням шляхів через `electronAPI.getPathForFile(file)`.

## 3. Команди запуску та збірки (Run & Build Commands)

| Команда | Опис |
| :--- | :--- |
| `npm start` | **Головна команда для запуску**. Запускає Vite dev server + Electron додаток з live-reload. |
| `npm run dev` | Синонім `npm start` (Vite + Electron). |
| `npm run app` | Синонім `npm start`. |
| `npm run build` | Компілює production бандл з **автоматичним інкрементом номера збірки** (`yyyy.mm.dd.X`). |
| `npm run build:dmg` | **Створює готовий Universal DMG пакет встановлення для macOS** (ARM64 + Intel x86_64 у папку `release/`). |
| `npm run build:dmg:universal` | Створює універсальний `.dmg` пакет для обох архітектур (Apple Silicon + Intel). |
| `npm run build:dmg:arm64` | Створює нативний Apple Silicon (M1/M2/M3/M4) `.dmg` пакет. |
| `npm run build:dmg:x64` | Створює нативний Intel (x86_64) `.dmg` пакет. |
| `npm run run:prod` | Збирає бандл та запускає його у продакшн режимі Electron. |
| `npm run lint` | Перевірка всього проєкту лінтером ESLint. |
| `npm run lint:fix` | Автоматичне виправлення помилок лінтера ESLint. |
| `npm run format` | Форматування кодової бази через Prettier. |
| `npm run fix` | **Головна команда для виправлення**: одночасний фікс ESLint та форматування Prettier. |

## 5. Гарячі клавіші (Keyboard Shortcuts)

### Навігація та панелі
- **`Tab`** — перемикання активного фокуса між лівою і правою панелями.
- **`Ctrl + Tab` / `Ctrl + Shift + Tab`** — циклічне перемикання між вкладками в активній панелі.
- **`Ctrl + U`** — поміняти ліву і праву панелі місцями (Swap Panes).
- **`↑` / `↓`** — переміщення курсора по списку файлів.
- **`Home` / `End`** — перехід на перший / останній елемент у списку.
- **`PageUp` / `PageDown`** — швидка прокрутка на 15 елементів угору / вниз.
- **`Backspace` або `Alt + ↑`** — перехід у батьківську директорію (`..`).
- **`Alt + ←` / `Alt + →`** — перехід назад / вперед по історії папок.
- **`Enter`** — відкриття папки, відкриття архіву у переглядачі `ArchiveViewModal`, або запуск файлу асоційованою нативною програмою macOS (`.app` запускається нативно).
- **`Alt + Enter`** — показати виділений елемент у Finder (Reveal in macOS Finder).

### Виділення файлів та розміри
- **`Space`** — на папці: **розрахунок її розміру всередині програми** (миттєво замінює мітку `<DIR>`); на файлі: інвертування виділення та перехід до наступного.
- **`Insert`** — виділення поточного файлу та перехід до наступного.
- **`Shift + Click`** — виділення безперервного діапазону файлів.
- **`Cmd + A` або `+` (`NumpadAdd`)** — виділити всі файли в активній панелі.
- **`-` (`NumpadSubtract`)** — зняти виділення з усіх файлів.
- **`*` (`NumpadMultiply`)** — інвертувати виділення в активній панелі.
- **Клік на вільне місце таблиці** — скидання виділення.

### Операції над файлами та архіви
- **`F1`** — шпаргалка гарячих клавіш.
- **`F2` або `Shift + F6`** — перейменування вибраного файлу або папки.
- **`F3`** — перегляд файлу (текст/код, зображення, Hex-дамп, QuickLook).
- **`F4`** — редагування файлу у вбудованому редакторі (`Cmd+S` для збереження).
- **`Shift + F4` / `+File`** — створення нового порожнього файлу.
- **`F5`** — копіювання виділених файлів у протилежну цільову панель.
- **`Shift + F5`** — створення дубліката / клону файлу в поточній папці (`filename - Copy.ext`).
- **`Alt + F5`** — **створення архіву (CreateArchiveModal: ZIP, TAR)**.
- **`F6`** — переміщення виділених файлів у цільову панель.
- **`Alt + F6`** — **вбудований перегляд та розпакування архіву (ArchiveViewModal)**.
- **`F7`** — створення нової папки.
- **`Alt + F7` або `F10`** — розширений пошук файлів за назвою або вмістом.
- **`Alt + L`** — **аналізатор великих файлів і диска (LargeFilesModal)**.
- **`Alt + D`** — **активні віртуальні пристрої та змонтовані образи (VirtualDisksModal)**.
- **`F8` або `Delete` або `Cmd + Backspace`** — переміщення вибраних елементів у macOS Смітник.
- **`Shift + Delete` або `Shift + F8`** — безповоротне видалення файлів (без Смітника, з підтвердженням).
- **`F9`** — відкриття поточної папки в терміналі macOS (`open -a Terminal`).

### Системні операції та буфер обміну
- **`Cmd + C`** — скопіювати вибрані файли у буфер обміну.
- **`Cmd + X`** — вирізати вибрані файли у буфер обміну.
- **`Cmd + V`** — вставити файли з буфера обміну у відкриту папку.
- **`Cmd + R`** — оновити вміст обох панелей.
- **`Cmd + Shift + .` або `Cmd + H`** — показати/приховати файли, що починаються з крапки (`.dotfiles`).
- **`Cmd + Shift + T`** — перемикання теми оформлення (Світла ☀️ / Темна 🌙).
- **`Cmd + D`** — швидкий перегляд списку дисків.
- **`Cmd + T`** — відкрити нову вкладку в активній панелі.
- **`Cmd + W`** — закрити поточну вкладку.
- **`Esc`** — закрити активне модальне або контекстне вікно.

## 6. Миша, зміна колонок та Контекстне меню

- **Перетягування межі колонок (Resizable Columns)**:
  - На межі між `NAME`, `EXT`, `SIZE`, `MODIFIED`, `PERMS` курсор змінюється на `col-resize`.
  - Затискання та перетягування мишею плавно змінює ширину стовпця.
  - Ширина зберігається у `localStorage`.
  - Подвійний клік по розділювачу скидає ширину колонки до стандартного значення.
- **Правий клік (Right Click)**:
  - **На папці**: Відкрити папку, **Порахувати розмір папки** (FolderSizeModal), **Пошук великих файлів** (LargeFilesModal), Створити ZIP-архів (Alt+F5), Копіювати, Перемістити, Перейменувати, Скопіювати шлях, Показати у Finder, Видалити у Смітник.
  - **На архіві**: Відкрити архів (ArchiveViewModal), Розархівувати сюди, Розархівувати у цільову панель, Копіювати, Перемістити, Видалити.
  - **На додатку (.app)**: Запустити програму, Показати вміст пакета, Показати у Finder, Видалити у Смітник.
  - **На звичайному файлі**: Відкрити у програмі, Перегляд QuickLook `F3`, Редагувати `F4`, Створити архів `Alt+F5`, Копіювати, Перемістити, Перейменувати, Скопіювати шлях, Показати у Finder, Видалити у Смітник.
  - **На порожньому місці**: Створити папку `F7`, Створити файл `Shift+F4`, **Пошук великих файлів**, Вставити з буфера `Cmd+V`, Виділити все `Cmd+A`, Відкрити Термінал `F9`, Оновити `Cmd+R`.
- **Подвійний клік (Double Click)**:
  - На папці — перехід усередину.
  - На рядку `.. [Parent Directory]` — перехід на рівень вище.
  - На архіві — відкриття `ArchiveViewModal` для перегляду та розпакування.
  - На `.app` — нативний запуск програми через macOS Finder.
  - На файлі — запуск асоційованою програмою macOS.

## 7. Drag & Drop функціонал

- **Підтримка дропу з Finder та Desktop**:
  - Файли та папки, перетягнуті з вікон macOS Finder або з Робочого столу, автоматично зчитуються через `electronAPI.getPathForFile(file)`.
- **Режими перетягування (Копіювання vs Переміщення)**:
  - Звичайне перетягування — копіювання (Copy).
  - Перетягування із затиснутою клавішею **`Shift`** — переміщення (Move) з відповідною підказкою курсора.
- **Цілі скидання**:
  - На протилежну панель або порожнє місце таблиці — операція виконується у відкриту папку панелі.
  - На конкретну підпапку в таблиці — операція виконується всередину цієї підпапки (підсвітка `is-drag-target`).
- **Захист від скидання в ту саму папку**: блокує випадкове перетягування одного файлу в директорію його поточного розташування.

## 8. Безпечне керування накопичувачами (DriveBar)

- Автоматичне виявлення томів `/Volumes`, системних розділів та підключених USB накопичувачів.
- Відображення обсягу вільного місця на плашках дисків.
- Кнопка вилучення (`CircleArrowUp`):
  - При натисканні відображає анімований індикатор `Loader2` (`.spin`).
  - **Захист від зайнятості ресурсу**: якщо відкрита панель або будь-яка вкладка переглядає диск, що вилучається, програма перед відмонтуванням автоматично перенаправляє їх у домашню папку `~`, звільняючи файлові дескриптори.
  - Нативне вилучення через macOS `diskutil unmount / eject`.
