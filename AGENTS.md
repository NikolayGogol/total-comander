# Total Commander for Windows — Developer & Agent Documentation

> **AGENTS.md**: Цей файл містить повну архітектурну документацію, правила розробки, дизайн-систему, структуру модулів, гарячі клавіші та інструкції запуску проєкту.

## 1. Загальний огляд проєкту (Project Overview)

**Total Commander for Windows** — сучасний orthodox двопанельний файловий менеджер для Windows, розроблений на базі:

- **Node.js (Runtime)** + **Electron**: робота з файловою системою Windows (диски `C:\`, `D:\`, `E:\`), переміщення у Кошик Windows (`shell.trashItem`), відкриття системного термінала (PowerShell / Windows Terminal / CMD) у поточній папці та запуск файлів у нативних програмах за замовчуванням.
- **Вбудований повнофункціональний архіватор**: додаток містить автономні бінарники в папці `bin/` (`7za.exe`, `rar.exe`, `unrar.exe`), які упаковуються в `resources/bin/`. Користувачеві **не потрібно встановлювати жодних сторонніх програм** для створення та розпакування архівів `ZIP`, `7Z`, `RAR`, `TAR`, `GZ` з підтримкою паролів і шифрування заголовків.
- **Аналізатор диска та великих файлів (Disk Cleanup / Large Files Finder)**: рекурсивний сканер для виявлення файлів гігантського розміру (>50MB, >100MB, >500MB, >1GB, >2GB або власний поріг) з можливістю швидкого виділення та звільнення пам'яті (переміщення у Кошик, безповоротне видалення).
- **Зміна ширини колонок перетягуванням (Resizable Columns)**: інтерактивні розділювачі на межах колонок (`NAME`, `EXT`, `SIZE`, `MODIFIED`) з плавним drag-and-drop, збереженням у `localStorage` та подвійним кліком для скидання ширини.
- **Розрахунок розміру папок усередині програми**: пункт контекстного меню «Порахувати розмір папки» (або клавіша `Space`), який миттєво замінює мітку `<DIR>` на точний розмір у байтах/ГБ без відкриття зовнішніх вікон Провідника.
- **Vue 3 (Composition API)** + **TypeScript**: реактивний інтерфейс, двопанельна координація, підтримка вкладок у кожній панелі, фільтрація, гарячі клавіші.
- **SCSS Design System**: повністю модульна система стилів без інлайн-стилів.
- **Day.js** (форматування дат) та **Numeral.js** (форматування розмірів файлів і чисел).
- **Lucide Icons**: семантичні системні іконки.

## 2. Суворі правила кодової бази (Mandatory Code Rules)

1. **Стилі виключно у SCSS файлах**:
   - Жодних блоків `<style>` у Vue-компонентах.
   - Усі стилі розташовані в `src/styles/` та імпортуються через `main.scss`.
2. **Кольори та розміри через змінні**:
   - Усі кольори визначені через SCSS змінні (`$color-bg-app`, `$color-accent-blue`, тощо).
   - Усі відступи (padding, margin), радіуси та розміри кнопок/панелей визначені через змінні (`$size-space-md`, `$radius-sm`, `$size-btn-icon`, тощо).
3. **Розміри шрифтів через змінні**:
   - Використовуються змінні: `$font-size-2xs`, `$font-size-xs`, `$font-size-sm`, `$font-size-base`, `$font-size-md`, `$font-size-lg`, `$font-size-xl`.
4. **Ніяких інлайн-стилів**:
   - Атрибут `style="..."` суворо заборонений у шаблонах `.vue`.
   - Замість цього використовуються семантичні класи або динамічні CSS Custom Properties, що встановлюються через DOM `element.style.setProperty()` в скриптах.
5. **Модульність та компонентний поділ**:
   - Кожен компонент має чітку відповідальність.
6. **Поведінка Explorer на подвійний клік**:
   - Подвійний клік на файл викликає асоційовану програму Windows (`electronAPI.openPath`).
   - Подвійний клік на архів (`.zip`, `.7z`, `.rar`, `.tar`, `.gz`, `.iso`) відкриває вбудований переглядач архівів `ArchiveViewModal`.
   - Подвійний клік на директорію переходить у неї.
7. **Форматування**:
   - Форматування дат: **`dayjs`** (`formatDate`).
   - Форматування чисел та розмірів байтів: **`numeral`** (`formatBytes`, `formatNumber`).
8. **Безпечна IPC-серіалізація (Structured Clone Safety)**:
   - Об'єкти та масиви з реактивного стану Vue 3 (Reactive Proxy) перед відправкою через `window.electronAPI` проходять очищення (`toPlain()` / JSON-серіалізацію), що унеможливлює помилку `DOMException: An object could not be cloned` в Electron.
9. **Версіонування та автоматичний білд**:
   - Версія програми задається в `package.json`.
   - Скрипт `scripts/update-build-info.js` автоматично генерує `src/buildInfo.ts` з номером версії, номером збірки (`BUILD_NUMBER`) та точною датою збірки (`BUILD_DATE`).
10. **Імпорти виключно через аліас `@/`**:
11. **Імпорти виключно через аліас `@/`**:

- Усі внутрішні імпорти компонентів, утиліт, сервісів та TypeScript-типів у папці `src/` суворо **мають використовувати аліас `@/`** замість відносних шляхів (`./`, `../`, `../../`).
- Наприклад:
  - `import TitleBar from '@/components/TitleBar.vue'`
  - `import type { FileItem } from '@/types'`
  - `import { formatBytes } from '@/utils/formatters'`
  - `import FileTable from '@/components/pane/FileTable.vue'`
- Використання відносних шляхів для внутрішніх модулів проєкту суворо заборонено.

- Усі внутрішні імпорти компонентів, утиліт, сервісів та TypeScript-типів у папці `src/` суворо **мають використовувати аліас `@/`** замість відносних шляхів (`./`, `../`, `../../`).
- Наприклад:
  - `import TitleBar from '@/components/TitleBar.vue'`
  - `import type { FileItem } from '@/types'`
  - `import { formatBytes } from '@/utils/formatters'`
  - `import FileTable from '@/components/pane/FileTable.vue'`
- Використання відносних шляхів для внутрішніх модулів проєкту суворо заборонено.

## 3. Команди запуску та збірки (Run & Build Commands)

| Команда                      | Опис                                                                                        |
| :--------------------------- | :------------------------------------------------------------------------------------------ |
| `npm start`                  | **Головна команда для запуску**. Запускає Vite dev server + Electron додаток з live-reload. |
| `npm run dev`                | Синонім `npm start` (Vite + Electron).                                                      |
| `npm run app`                | Синонім `npm start`.                                                                        |
| `npm run build`              | Компілює бандл (Vue UI в `dist/`, Electron main/preload в `dist-electron/`).                |
| `npm run build:win`          | **Створює інсталятори для Windows** (NSIS інсталятор та Portable .exe у `release/`).        |
| `npm run build:win:x64`      | Створює 64-бітний Windows NSIS інсталятор (`.exe`).                                         |
| `npm run build:win:portable` | Створює портативну версію Windows без встановлення.                                         |
| `npm run build:win:arm64`    | Створює Windows інсталятор для пристроїв ARM64.                                             |
| `npm run run:prod`           | Збирає бандл та запускає його у продакшн режимі Electron.                                   |
| `npm run lint`               | Перевірка всього проєкту лінтером ESLint.                                                   |
| `npm run lint:fix`           | Автоматичне виправлення помилок лінтера ESLint.                                             |
| `npm run format`             | Форматування кодової бази через Prettier.                                                   |
| `npm run fix`                | **Головна команда для виправлення**: одночасний фікс ESLint та форматування Prettier.       |

## 5. Гарячі клавіші (Keyboard Shortcuts)

- **`Tab`** — перемикання активного фокуса між лівою і правою панелями.
- **`↑` / `↓`** — переміщення курсора по списку файлів.
- **`Space`** — на папці: **розрахунок її розміру всередині програми**; на файлі: інвертування виділення та перехід до наступного.
- **`Insert`** — виділення поточного файлу та перехід до наступного.
- **`Enter`** — відкриття папки, перехід до файлу, або відкриття архіву у вбудованому переглядачі.
- **`Backspace`** — перехід у батьківську директорію (`..`).
- **`F1`** — довідка та шпаргалка гарячих клавіш.
- **`F2` або `Shift + F6`** — перейменування вибраного файлу або папки.
- **`F3`** — перегляд файлу (текст/код, зображення, Hex-дамп).
- **`F4`** — редагування файлу у вбудованому редакторі (`Ctrl+S` для збереження).
- **`Shift + F4` / `+File`** — створення нового порожнього файлу.
- **`F5`** — копіювання виділених файлів у цільову протилежну панель.
- **`Shift + F5`** — дублювання / клонування у поточну папку (Clone).
- **`Alt + F5`** — **створення архіву (ZIP, 7Z, RAR)** з паролем та вибором рівня стиснення.
- **`F6`** — переміщення виділених файлів у цільову панель.
- **`Alt + F6`** — **вбудований перегляд та розпакування архіву**.
- **`F7`** — створення нової папки.
- **`Alt + F7` або `F10`** — розширений пошук файлів за маскою або текстом всередині.
- **`F8` або `Delete`** — переміщення вибраних елементів у Кошик Windows.
- **`Shift + Delete` або `Shift + F8`** — безповоротне видалення (минаючи Кошик).
- **`F9`** — відкриття поточної папки в Терміналі Windows (PowerShell / CMD).
- **`Alt + Enter`** — показати вибраний елемент у Провіднику Windows (Explorer).
- **`Alt + ←` / `Alt + →`** — перехід назад / вперед по історії перегляду папок.
- **`Alt + ↑`** — перехід у батьківську директорію.
- **`Ctrl + Tab` / `Ctrl + Shift + Tab`** — перемикання між вкладками в активній панелі.
- **`Ctrl + U`** — поміняти ліву і праву панелі місцями (Swap Panes).
- **`Ctrl + R`** — оновлення вмісту обох панелей.
- **`Ctrl + Shift + .` або `Ctrl + H`** — показати/приховати приховані файли.
- **`Ctrl + Shift + T`** — перемикання теми оформлення (Світла ☀️ / Темна 🌙).
- **`Ctrl + T`** — відкрити нову вкладку в активній панелі.
- **`Ctrl + W`** — закрити поточну вкладку.
- **`Ctrl + A` або Numpad `+`** — виділити всі файли в активній панелі.
- **`*` або Numpad `*`** — інвертувати виділення в активній панелі.
- **Numpad `-`** — зняти виділення з усіх файлів.
- **`Ctrl + C`** — скопіювати вибрані файли у буфер обміну.
- **`Ctrl + X`** — вирізати вибрані файли у буфер обміну.
- **`Ctrl + V`** — вставити файли з буфера обміну у відкриту папку.
- **`Ctrl + D`** — швидкий список підключених дисків.
- **`Esc`** — закрити активне модальне вікно або зняти контекстне меню.

## 6. Миша та Контекстне меню (Mouse Support & Context Menu)

- **Правий клік (Right Click)**:
  - **На папці**: Відкрити, **Порахувати розмір папки** (модалка аналізу папок), **Пошук великих файлів**, Архівувати (ZIP / 7Z / RAR), Копіювати, Перемістити, Перейменувати, Скопіювати шлях, Показати у Провіднику, Видалити у Кошик.
  - **На архіві**: Відкрити, Розархівувати вміст, Переглянути, Копіювати, Перемістити, Видалити.
  - **На звичайному файлі**: Відкрити, Переглянути `F3`, Редагувати `F4`, Архівувати, Копіювати, Перемістити, Перейменувати, Скопіювати шлях, Показати у Провіднику, Видалити.
  - **На порожньому місці таблиці**: Нова папка `F7`, Новий файл `Shift+F4`, **Пошук великих файлів**, Вставити з буфера `Ctrl+V`, Виділити все `Ctrl+A`, Відкрити Термінал `F9`, Оновити `Ctrl+R`.
- **Подвійний клік (Double Click)**:
  - На папці — перехід усередину директорії.
  - На рядку `.. [Parent Directory]` — перехід на рівень вище.
  - На архіві — відкриття вбудованого інструменту читання/розпакування архівів.
  - На файлі — запуск асоційованою програмою Windows за замовчуванням.
- **Перетягування межі колонок (Column Resizing)**:
  - На межі між `NAME`, `EXT`, `SIZE`, `MODIFIED` курсор змінюється на `col-resize`.
  - Затискання та перетягування мишею миттєво змінює ширину стовпця.
  - Подвійний клік по розділювачу скидає ширину колонки до початкового значення.

## 7. Drag & Drop функціонал

- Перетягування виділених файлів:
  - На протилежну панель або порожнє місце таблиці — копіювання/переміщення в поточну відкриту директорію.
  - На конкретну підпапку в таблиці — копіювання/переміщення безпосередньо всередину цієї підпапки (з візуальним виділенням цілі `is-drag-target`).
  - З зовнішнього Провідника Windows у будь-яку панель програми.
